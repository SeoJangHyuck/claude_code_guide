## 슬라이드 4-2 — Claude Code로 일하는 흐름 4단계 (3분 30초)

**핵심 메시지**: "skill·hook 같은 기능은 여러 도구에 공통이다 (2026.11 기준). Claude Code는 한 번 만든 설정을 VS Code·데스크톱·터미널 어디서든 그대로 쓴다 — 시작·작업·자산화·공유 순서로 4가지."

```

Subagents는 일을 나눠 맡는 보조 작업자예요 — 긴 작업·여러 자료를 각자 격리된 컨텍스트(별도 작업 공간)에서 병렬로 처리합니다. 그리고 Hook — 정해진 순간 자동 실행되는 동작으로, 33개 이벤트에 걸 수 있어요. 세션 시작, 프롬프트 제출, 도구 실행 전후, 응답 종료 같은 정해진 시점에 Claude 판단과 상관없이 자동으로 실행됩니다. 슬라이드의 '작업 전 막기'는 도구 실행 전(PreToolUse)에 거는 hook으로, 내가 정한 규칙에 걸리면 실행 자체를 막을 수 있어요. MCP가 오픈 표준이라 다른 도구용으로 만든 MCP 서버도 Claude Code에 등록하면 그대로 쓸 수 있고요. GitHub에 OSS 자산도 빠르게 쌓이고 있습니다 — Anthropic 공식 저장소인 anthropics/skills와 anthropics/claude-plugins-official, 커뮤니티 모음인 awesome-claude-code 같은 리포들이에요.
