# 챕터 9: 마무리 — 내일 시작 3단계 (1슬라이드 / 1분)

> 톤 가이드: 1시간 회고. 청중이 "내일 진짜 시작할 수 있다"는 확신을 가지고 강당을 나가도록.

(장 표지 부제: "거창하지 않게 — 매주 반복하는 작업 하나만 골라서.")

---

## 슬라이드 9-1 — 내일 시작 3단계 (1분)

**핵심 메시지**: "1단계 5분, 2단계 30분, 3단계 1시간 — 이번 주 안에 모두 가능."

**본문 콘텐츠**:

```
내일부터 시작하는 3단계
거창하게 생각하지 말 것. 반복 작업 하나부터 시작.

  ───────────────────────────────────────────

  1️⃣  Claude Code 설치
       VS Code 확장에서 "Claude Code" 설치
       → 유료 Claude 플랜 또는 개발자용 Console 계정으로 로그인

  2️⃣  CLAUDE.md 작성
       매주 반복하는 작업 1개의 톤·규칙·폴더 구조를
       CLAUDE.md(매번 자동으로 읽히는 지침) 한 페이지로 정리

  3️⃣  skill로 정리해 공유
       그 작업 절차를 skill(재사용 절차서)로 정리
       → 작업 폴더째 동료와 공유
       (개인 설정 파일 제외)

  ───────────────────────────────────────────

  오늘 자리 돌아가셔서 매주 반복하는 작업 하나만 떠올려 보세요. 거기가 출발점입니다.
```

**발표 노트 (1분)**:
> "오늘 들으신 모든 게 결국 이 3단계로 압축됩니다.
>
> 1단계, Claude Code 설치. VS Code 확장 마켓에서 검색해서 설치하고, Pro 같은 유료 플랜이나 개발자용 Console 계정으로 로그인하면 5분이에요. 무료 플랜으로는 안 됩니다. 회사에서 쓰던 VS Code(1.94 이상)에 확장만 추가하면 되고, VS Code가 없으시면 터미널이나 데스크톱 앱으로도 쓸 수 있습니다(데스크톱 앱은 Pro 같은 유료 플랜 구독 계정이 필요). 7장에 나온 claude로 시작하는 터미널 명령은 CLI를 따로 설치해야 쓸 수 있고요. 확장만 설치해서는 터미널에 claude 명령이 생기지 않습니다.
>
> 2단계, 매주 반복하는 작업 한 개만 골라서 작업 폴더(VS Code에서 연 폴더) 맨 위나 .claude 폴더에 CLAUDE.md를 작성해보세요. CLAUDE.md는 Claude Code가 대화를 시작할 때마다 자동으로 읽는 지침 파일이라, 그 작업의 톤과 규칙, 어떤 폴더에 무엇이 있는지를 한 페이지로 적어 두면 됩니다. 30분이면 충분합니다.
>
> 3단계, 그 작업 절차를 skill로 정리합니다. `.claude/skills/<이름>/SKILL.md` 파일 하나가 skill 하나예요. 그다음 작업 폴더째 — CLAUDE.md와 .claude 폴더가 함께 갑니다 — git 저장소에 커밋하거나 작업 폴더를 zip으로 옆자리에 한 번 공유. 1시간. 커밋할 때나 zip으로 보낼 때나 모두 `.claude/settings.local.json`과 `CLAUDE.local.md` 같은 개인 파일은 빼 주세요. 명령 실행 권한 창에서 다시 묻지 않기를 고르면(터미널은 'Yes, and don't ask again', VS Code는 'Yes, allow … for this project' 같은 문구) 그 허용 규칙이 settings.local.json에 저장될 수 있는데, 그대로 보내면 동료가 폴더를 신뢰하는 순간 내 허용 규칙이 동료 PC에도 적용됩니다. Claude Code가 이 파일을 git 제외 목록에 자동으로 넣는 건 git 저장소 안에서 처음 쓸 때뿐이라, git 없이 쓰던 폴더를 나중에 git으로 올리면 이 파일이 같이 올라갈 수 있습니다.
>
> 다 합쳐도 1시간 35분이에요. 이번 주 안에 다 가능합니다. 거창하게 생각하지 마시고, 오늘 자리 돌아가셔서 매주 반복하는 작업 하나만 떠올려 보세요. 거기가 출발점입니다.
>
> 그럼 마지막으로 Q&A 시간 가지겠습니다."

**시각 표현 메모**:
- 3단 카드.
- 각 단계 번호·이름 강조. 소요 시간(5분·30분·1시간, 합계 1시간 35분)은 슬라이드에 없이 발표 노트로만.
- 마지막 줄("매주 반복하는 작업 하나만 떠올려 보세요") 강조.
- CLAUDE.md 위치(루트 또는 .claude/), skill 경로, VS Code 1.94 이상, VS Code 대신 쓸 수 있는 터미널·데스크톱 앱, CLI 별도 설치, 개인 파일 이름(settings.local.json·CLAUDE.local.md)은 발표 노트로.
- 3단계 이름은 "skill로 정리해 공유" — 7장에서 '묶음'은 plugin을 뜻하므로 "묶고"를 쓰지 않음. 공유 표현은 덱 전체와 같게 "작업 폴더째 동료와 공유(개인 설정 파일 제외)"(CLAUDE.md·.claude/ 표기는 노트로). Console은 "개발자용 Console 계정".
- 마지막 멘트에서 챕터 10 (Q&A)으로 자연 연결.
